# M1 验收清单（功能与工程验收通过）

用户已追加授权 M1。下列勾选项由自动测试和合成资料 Chrome 流程验证，个人真实经历试用单独保留待验收。

## 手动项目流程

- [x] 主页统一编辑器录入项目名称与原文，至少覆盖个人项目、单位项目、工作/研究阶段概括各一条。
- [x] 名称留空时从原文首个非空行生成简短显示名称，无模型调用。
- [x] Save as new 持久化成功后再给出可跳过的单位与年份补充。
- [x] 跳过、取消或元数据补充失败仍保留已保存原文；补充更新同一 ID，不重复新建。
- [x] 单位留空显示“个人项目”；时间可空、按年或至今；遵守数据约定中的年份不变量。
- [x] 刷新与关闭后重新打开同一 origin，原文与元数据保持一致。

## 覆盖、浏览和编辑

- [x] Overwrite existing 选择目标时展示名称、单位和时间，按钮明确显示覆盖对象。
- [x] 覆盖后数量、ID、创建时间不变；原单位和时间默认保留；名称留空保留目标名称、明确填写才改名；其他项目不变。
- [x] 项目 tab 展示名称、单位、年份和原文前一两行，可展开全文；无 AI 摘要替代原文。
- [x] Edit 载入主页同一编辑器，明确显示编辑目标、主操作为保存修改。
- [x] 切换新建或编辑不会误覆盖目标；另建项目需明确切换模式。
- [x] 删除前展示目标并确认；不建立事实审核或复杂版本历史。

## Basic Info 与可靠保存

- [x] Basic Info 在独立 tab 直接编辑并明确保存，只用固定 `basic_info` ID，反复保存不新增记录。
- [x] Basic Info 固定单位 `basic info`，按 `type` 识别；不进入项目列表，无年份字段。
- [x] 超过 500 计数单位的 Basic Info 可保存，不使用普通项目上限。
- [x] 项目复用 M0 计数函数；单字可接受、空白/纯符号提示为空、500 接受、501 保留输入并提示。
- [x] 保存中、成功和失败状态准确；只有事务完成才显示成功，失败保留输入，连续点击不产生重复记录。
- [x] 应用内离开未保存内容时提示；浏览器 Back/Forward 取消保留原历史项与草稿，相同 URL 的记录项也正确处理且一次跳转只确认一次。M2 将进一步完善这些状态和错误处理。
- [x] 手动维护无模型、后端或外部请求；不引入 verify、proposals 或旧版兼容结构。

## 交付节奏

- [x] 对 ID 保留、元数据保留、Basic Info 唯一性、持久化失败、刷新读取等实际风险写必要测试。
- [x] 在真实浏览器从空白完成上述场景。
- [ ] 用真实经历建立一份 Profile，修复实际录入问题，记录验收结果后再决定是否开始 M2。

M1 不包含备份恢复（M2）、简历导入（可选 M3）、Job Analysis、Resume Generation 或雇主分享。
