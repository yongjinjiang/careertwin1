# M1 实施与验证记录

日期：2026-10-19（America/Denver）。状态：**M1 功能已实现，工程与合成资料浏览器验收通过**。真实经历试用尚待用户完成，不冒充已完成个人资料整理。M2 及后续未开始。

## 交付行为

- 主页为唯一项目编辑器；新建和编辑模式明确，名称留空使用原文首个非空行，超长名称按 40 个 Unicode code point 截取并加省略号。
- Save as new 先提交名称与原文，再给出单位和年份的可跳过补充。保存成功自动进入同一项目的编辑模式，连续点击、同会话重试不重复新建。
- 元数据取消、跳过或失败不会丢失已存原文，补充只更新已保存 ID；失败保留未提交的补充输入。
- Overwrite existing 无默认目标。选择器显示名称、单位、年份，执行按钮显示目标名；仅更新指定项目名称/原文，保留 ID、创建时间和默认元数据。
- 项目列表显示名称、单位、年份、原文两行摘录，支持全文展开、Edit 返回统一编辑器、目标明确的删除确认。
- Basic Info 在独立 tab 直接编辑与保存，固定 ID 和单位，保持一条记录，不进入项目列表，无项目 500 字限制。
- 表单与仓库共享计数/校验，原文不静默截断或去空白。项目单字允许，0 计数单位拒绝，500 允许，501 拒绝。
- 成功以 IndexedDB transaction complete 为准；abort 不显示成功，保留输入。未保存修改有标识，应用内导航和新建切换需确认，保存中阻止切页，浏览器离页注册 beforeunload。
- 没有模型调用、后端、登录、云同步或旧数据迁移；未提前实现备份恢复和下游功能。
